# 🚲 BikinMars (v2)

Une application web moderne, fluide et élégante de cartographie en temps réel du service de vélos en libre-service **Levélo** à Marseille.

👉 **[Accéder à l'application en direct](https://ploa33.github.io/bikinmars/)**

---

## ✨ Fonctionnalités

- 🎨 **Interface Premium** : Thème sombre moderne style *glassmorphism* optimisé pour mobile et desktop.
- 🗺️ **Carte Leaflet Améliorée** : Basée sur les tuiles *CartoDB Dark Matter*.
- 🟢 **Statut Dynamique** : Couleur et taille des stations adaptées en temps réel à leur taux d'occupation.
- 🔋 **Détails des Vélos** : Répartition entre vélos électriques (avec niveau de batterie en kilomètres) et vélos mécaniques.
- 🚲 **Vélos Free-Floating** : Affichage des vélos individuels isolés hors station en zoomant sur la carte.
- 🔗 **Intégration Mobile** : Liens profonds (*deep-links*) pour ouvrir les stations directement dans l'application officielle **Levélo** afin de déverrouiller un vélo rapidement, et liens d'itinéraires vers Google Maps.
- 🔄 **Données Fiables** : Rafraîchissement automatique toutes les 60 secondes avec indicateur visuel de chargement et système de proxy de secours automatique (CORS fallback).

---

## 🛠️ Stack Technique

- **Core** : HTML5, CSS3, JavaScript (ES6+) Vanilla
- **Cartographie** : Leaflet.js
- **API** : Flux GBFS (General Bikeshare Feed Specification) temps réel de Marseille
- **Hébergement** : GitHub Pages
